Arsitektur Pipeline Ekstraksi

Penyaring Galley & Unduhan: Menepis URL galley viewer (/article/view/{id}/{galleyId}) dan file direct-download guna mencegah artikel duplikat "View of...".
Jsoup Cascading Extractor: Ekstraksi meta tag Highwire Press & Dublin Core dengan fallback CSS selector DOM OJS modern.
Deduplikasi 3 Lapis: Mengeliminasi data duplikat lewat URL Kanonikal, normalisasi DOI, dan sidik jari semantik (Judul + Penulis + Tahun).
Sanitasi & Quality Gate: Menolak *ghost records* tanpa atribut akademik dan menormalisasi mojibake UTF-8.
